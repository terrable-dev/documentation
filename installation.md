# Installation

There are a few supported ways you can install the Terrable CLI.

## Scoop

```shell
scoop bucket add terrable https://github.com/terrable-dev/scoop.git
scoop install terrable
```

## Homebrew

```shell
brew tap terrable-dev/tap
brew install terrable
```

## Go

```shell
go install github.com/terrable-dev/terrable@latest
```

## Release artifacts

All release artifacts are provided via the
[GitHub Releases](https://github.com/terrable-dev/terrable/releases), if you
would like to install manually or as a workaround if your preferred installation
method is not available.
